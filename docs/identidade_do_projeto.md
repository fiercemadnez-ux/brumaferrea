# Identidade do projeto

- **Franquia:** Os Cânticos dos Sete
- **Título deste jogo:** Os Cânticos dos Sete: Brumaférrea
- **Planeta:** Kanthalos
- **Região principal:** província de Brumaférrea

Use o título completo em textos de interface, documentação e materiais do projeto. Use **Os Cânticos dos Sete** para se referir à franquia. Não use o nome de desenvolvimento antigo como título atual.

## Menu principal

- A tela inicial reutiliza a paisagem 3D existente de `assets/world/overworld.glb`; não cria uma montanha ilustrativa separada.
- A câmera enquadra a crista de maior altitude da malha de Brumaférrea e se desloca lentamente, mantendo o relevo como foco visual.
- O menu usa céu, luz e névoa próprios, sem iniciar a simulação de NPCs, inimigos ou rotinas enquanto está na tela inicial.
- A interface mostra apenas o título do jogo e ações de menu, sem slogan ou texto promocional.
